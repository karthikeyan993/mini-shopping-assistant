Before problem one

DSA stands for data structures and algorithms. A data structure determines which operations are cheap. An algorithm is the sequence of steps that turns the input into the answer.

Read Python by hand

nums = [4, 7, 9] puts 4 at index 0. nums[-1] is 9. nums[0:2] copies [4, 7]. The stop index is excluded. Strings use the same indexing rules and their characters cannot be overwritten.

for i, x in enumerate([4, 7]):
    print(i, x)
# 0 4
# 1 7

range(3) yields 0, 1, 2. A while loop repeats while its condition is true. return ends the function immediately. Indentation tells you which statements repeat.

Estimate cost from the input

Let n count input items. Doubling n leaves constant work alone, adds about one step to binary search, doubles a linear scan, and roughly quadruples all-pairs work. Two consecutive scans are still O(n).

n = 1,024 items
one lookup           ≈ 1 operation on average
halve until one      = 10 halvings
visit every item     = 1,024 visits
try all i < j pairs  = 523,776 pairs

Big O describes growth. Name extra storage separately, including call frames. Copying a list of n elements takes O(n) time and space.

Use set() for an empty set. {} creates an empty dictionary. Dictionary keys and set members must be hashable, such as a string, integer, or pair of integers.

See what Python shares

a = [4]
b = a
b.append(7)    # a is now [4, 7]
c = a.copy()
c.pop()        # a still holds [4, 7]

Assignment gives an object another name. A shallow copy creates a new outer list and shares any children. For independent matrix rows use [[0] * cols for _ in range(rows)]. A node reference works like a name. Setting node.next changes the link on that object.

Recognize repeated work

With recursion, each call solves a smaller case. It must reach a stopping case. For a sum through n, sum(3) asks for 3 + sum(2), then 2 + sum(1), ending at sum(0) = 0. Values return through the waiting calls.

go down     3 → 2 → 1 → 0
come back   6 ← 3 ← 1 ← 0

DFS uses this last-in, first-out order. Backtracking explores several choices and undoes each change. When different choices repeatedly ask for the same smaller answer, store it. This leads to dynamic programming.

Say the contract and invariant

The contract states what goes in and what must come out. An invariant is a fact that remains true at a chosen point in each loop. It explains why your next move is safe.

For Two Sum, ask “Indices or values? Can I use an element twice?” Then say “Before each lookup, my dictionary contains only earlier indices.” Try [4, 4] with target 8. Returning [0, 1] respects both the contract and the invariant.

Know the words substring (contiguous characters), subsequence (may skip items, preserves order), and subset (select any items). For “abc”, “ac” is a subsequence.

Lesson 01 / Easy

Arrays & hash maps

Two Sum ↗ LC 1

Know first Index, enumerate, dictionary lookup.

Two prices sum to a target. Return their two different positions. Assume exactly one pair exists.

Reason it out

Trying every pair costs O(n²). For each price x, ask whether target − x has already appeared. Keep the index of each earlier price so a successful lookup gives both positions.

Python solution & edge cases 
def two_sum(nums, target):
    seen = {}
    for i, value in enumerate(nums):
        needed = target - value
        if needed in seen:
            return [seen[needed], i]
        seen[value] = i

Run these checks

assert two_sum([4, 7, 4], 8) == [0, 2]
assert two_sum([-3, 5, 1], 2) == [0, 1]

Cost O(n) expected time · O(n) extra space. One expected constant-time lookup per price.

Pitfall Inserting first can pair a price with itself. Also, index 0 is falsy in Python. Use membership to check whether a price exists.

Could you use less memory if the prices were sorted?

Yes. Compare the sum of the two ends to the target. A small sum rules out the current left end, and a large sum rules out the right end. This takes O(n) time and O(1) extra space.

Lesson 02 / Easy

Strings & two pointers

Valid Palindrome ↗ LC 125

Know first String indexing, inclusive endpoints, isalnum() and lower().

Read a phrase forward and backward, ignoring punctuation, spaces and letter case. Do the letters and digits match?

Reason it out

Building a cleaned string and reversing it is simple but allocates O(n) space. Instead, skip punctuation at each end. Once the two outer characters match, only the middle can still fail.

Python solution & edge cases 
def is_palindrome(s):
    left, right = 0, len(s) - 1
    while left < right:
        if not s[left].isalnum():
            left += 1
        elif not s[right].isalnum():
            right -= 1
        elif s[left].lower() != s[right].lower():
            return False
        else:
            left += 1
            right -= 1
    return True

Run these checks

assert is_palindrome("A, ba")
assert is_palindrome("., ")
assert not is_palindrome("0P")

Cost O(n) time · O(1) extra space for the ASCII input. Each pointer crosses each position at most once.

Pitfall Digits count. Test punctuation-only input and a pair like '0P'. Guard both pointers when skipping characters.

What does an empty cleaned string return?

True. There is no conflicting pair. The loop also handles a single remaining character.

Lesson 03 / Medium

Sliding window

Longest Substring Without Repeating Characters ↗ LC 3

Know first Two pointers from lesson 2, set membership, contiguous slices.

Find the length of the longest uninterrupted stretch of distinct characters.

Reason it out

Grow the right edge by one character. If that character is already in the window, remove characters from the left until its old copy leaves. After insertion the set contains exactly the current window, with one copy of each character.

Python solution & edge cases 
def longest_unique(s):
    window = set()
    left = best = 0
    for right, char in enumerate(s):
        while char in window:
            window.remove(s[left])
            left += 1
        window.add(char)
        best = max(best, right - left + 1)
    return best

Run these checks

assert longest_unique("abba") == 2
assert longest_unique("abcc") == 3
assert longest_unique("") == 0

Cost O(n) time on average · O(u) extra space for up to u distinct characters. Across all iterations, each character enters and leaves at most once.

Pitfall A single if can leave the duplicate inside the window. A substring must be contiguous. Skipping the middle character changes the problem.

Why can the best length stay the same after a shrink?

The required answer may end earlier. For 'abcc', the best is 3 even though the final window contains only the last 'c'.

Lesson 04 / Easy

Stacks

Valid Parentheses ↗ LC 20

Know first List append/pop, dictionary lookup. Input consists only of brackets.

Does each closing bracket match the most recent unmatched opening bracket, with every opener eventually closed?

Reason it out

A stack stores unfinished openers. A closer must match the top because a nested pair closes before its parent. Counting bracket types loses that order.

Python solution & edge cases 
def valid_brackets(s):
    matching = {")": "(", "]": "[", "}": "{"}
    stack = []
    for char in s:
        if char in matching:
            if not stack or stack.pop() != matching[char]:
                return False
        else:
            stack.append(char)
    return not stack

Run these checks

assert valid_brackets("([])")
assert not valid_brackets("([)]")
assert not valid_brackets(")")
assert not valid_brackets("(")

Cost O(n) time · O(n) extra space in the worst case of n opening brackets.

Pitfall Check for an empty stack before popping. After the scan, an opener left on the stack means the input is incomplete.

Could one integer replace the stack?

For a single bracket type, count openers minus closers, reject a negative prefix and require zero at the end. Multiple types also require the order.

Lesson 05 / Easy

Binary search

Binary Search ↗ LC 704

Know first Sorted order, list indexing, integer division //.

Find the index of a target in an ascending array of distinct integers. Return −1 if absent.

Reason it out

A linear scan checks each element. In a sorted array, comparing against the middle rules out a whole half. Keep a closed interval [left, right] that still contains every possible answer.

Python solution & edge cases 
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

Run these checks

assert binary_search([2, 5, 9, 12, 17], 12) == 3
assert binary_search([2], 2) == 0
assert binary_search([2], 1) == -1

Cost O(log n) time · O(1) extra space. Each miss at least halves the remaining candidates.

Pitfall For closed bounds, use left <= right. Move past mid on a miss or the last candidate can repeat forever.

How would you find the first value ≥ target?

Use [left, right) with right = len(nums). While left < right, set right = mid when nums[mid] >= target, otherwise left = mid + 1. Return left. It can equal len(nums).

Lesson 06 / Easy

Linked lists

Reverse Linked List ↗ LC 206

Know first A node stores a value and a reference called next. None marks the end.

Reverse the links of a singly linked list and return the new head.

Reason it out

Keep the reversed prefix in prev and the untouched suffix in head. Save the next node before turning the current link around. Each step transfers exactly one node from the suffix to the prefix.

Python solution & edge cases 
def reverse_list(head):
    prev = None
    while head is not None:
        following = head.next
        head.next = prev
        prev = head
        head = following
    return prev

Run these checks

from types import SimpleNamespace
tail = SimpleNamespace(val=9, next=None)
middle = SimpleNamespace(val=7, next=tail)
head = SimpleNamespace(val=4, next=middle)
assert reverse_list(head) is tail
assert tail.next is middle and middle.next is head
assert head.next is None
assert reverse_list(None) is None

Cost O(n) time · O(1) extra space. Recursive reversal also visits n nodes but uses a call frame per node.

Pitfall Overwriting head.next too soon loses the rest of the list. Moving the local name head alone does not change a link.

How would you check for a cycle before reversing?

Move a slow pointer one link and a fast pointer two links. Inside a cycle the faster pointer gains one position per turn until they meet. If fast reaches the end, there is no cycle.

Lesson 07 / Medium

Trees & depth-first search

Validate Binary Search Tree ↗ LC 98

Know first A binary node has val, left and right. A subtree is a node and all its descendants. Review the stack in lesson 4.

Every value on a node’s left must be smaller, and every value on its right larger. Decide whether the entire tree obeys this rule.

Reason it out

A depth-first search (DFS) follows one branch before returning to a sibling. Carry the tightest lower and upper bounds from all ancestors. The left child inherits a tighter upper bound, the right child a tighter lower bound.

Python solution & edge cases 
def valid_bst(root):
    stack = [(root, float("-inf"), float("inf"))]
    while stack:
        node, low, high = stack.pop()
        if node is None:
            continue
        if not low < node.val < high:
            return False
        stack.append((node.right, node.val, high))
        stack.append((node.left, low, node.val))
    return True

Run these checks

from types import SimpleNamespace
def node(value, left=None, right=None):
    return SimpleNamespace(val=value, left=left, right=right)

assert valid_bst(node(5, node(2), node(8)))
assert not valid_bst(node(5, node(2), node(8, node(4))))
assert not valid_bst(node(5, node(5)))

Cost O(n) time · O(h) extra space, where h is tree height. A skewed tree can have h = n.

Pitfall A parent-only check accepts the 4 under 8. Equality also fails the strict BST rule. An explicit stack works for trees deeper than Python’s recursion limit.

Could an inorder walk validate the same tree?

Yes. Visit left subtree, node, then right subtree. The values must increase strictly. Remembering just the previous value plus the traversal stack is enough.

Lesson 08 / Medium

Grids & breadth-first search

Number of Islands ↗ LC 200

Know first A grid cell (r, c) is a graph vertex. Its up to four side-neighbors are connected by edges. A deque visits the oldest pending cell first.

Count groups of land cells ('1') connected up, down, left or right in a rectangular grid.

Reason it out

Scan for unseen land. Each fresh starting cell belongs to a new island. Use breadth-first search (BFS) to flood its whole component before resuming the scan. Mark cells as water as soon as they enter the queue.

Python solution & edge cases 
from collections import deque

def count_islands(grid):
    if not grid or not grid[0]:
        return 0
    rows, cols = len(grid), len(grid[0])
    count = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] != "1":
                continue
            count += 1
            grid[r][c] = "0"
            queue = deque([(r, c)])
            while queue:
                row, col = queue.popleft()
                for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    nr, nc = row + dr, col + dc
                    if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == "1":
                        grid[nr][nc] = "0"
                        queue.append((nr, nc))
    return count

Run these checks

assert count_islands([list(s) for s in ("110", "010", "001")]) == 2
assert count_islands([list("000")]) == 0
assert count_islands([list("111")]) == 1

Cost O(R × C) time · O(R × C) worst-case queue space. Each land cell is enqueued once.

Pitfall Diagonals do not connect. Python accepts negative indices, so check both lower bounds. This version consumes the input grid.

What if the interviewer needs the grid unchanged?

Track discovered coordinates in a set. A DFS stack also counts components. A FIFO queue additionally visits cells in order of edge distance from the start.

Lesson 09 / Medium

Sorting & intervals

Merge Intervals ↗ LC 56

Know first A closed interval [a, b] includes both endpoints. sorted() orders pairs by start, then end.

Combine overlapping closed intervals and return disjoint ranges that cover the same points.

Reason it out

Sort by start. Keep the output ranges in order. Only the last one can overlap the next interval because all earlier ones already end before the last one starts.

Python solution & edge cases 
def merge_intervals(intervals):
    merged = []
    for start, end in sorted(intervals):
        if merged and start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged

Run these checks

assert merge_intervals([[5,7], [1,3], [3,6], [9,9]]) == [[1,7], [9,9]]
assert merge_intervals([[1,9], [3,4]]) == [[1,9]]

Cost O(n log n) time · O(n) extra space for sorted input and up to n output ranges.

Pitfall Use max for the merged end. Replacing the end with the next end shrinks [1,9] when [3,4] arrives.

Would the touching ranges [1,3) and [3,5) overlap?

They share no point. If the specification combines only overlaps, start a new range at equality for half-open intervals. In this exercise both endpoints are inclusive.

Lesson 10 / Medium

Heaps & top k

Kth Largest Element in an Array ↗ LC 215

Know first A min-heap is a collection whose smallest member is at index 0. Insertion and removing the minimum each cost O(log k) for k items.

Return the kth largest value, counting duplicates. For example, the second largest of [8,8,1] is 8.

Reason it out

Keep the largest k values seen. The smallest retained value is the cutoff. When a larger score arrives, replace that cutoff. This also works when scores arrive one at a time.

Python solution & edge cases 
from heapq import heappush, heapreplace

def kth_largest(nums, k):
    heap = []
    for value in nums:
        if len(heap) < k:
            heappush(heap, value)
        elif value > heap[0]:
            heapreplace(heap, value)
    return heap[0]

Run these checks

assert kth_largest([4, 7, 3, 6], 2) == 6
assert kth_largest([8, 8, 1], 2) == 8
assert kth_largest([-5, -2], 1) == -2

Cost O(n log(k+1)) time · O(k) extra space. Reading every value still takes O(n) when k = 1.

Pitfall A heap’s internal list is only partially ordered. heap[0] is the cutoff. Converting the scores to a set loses repeated ranks.

Why choose this for the best ten search results?

An incoming score can be discarded immediately or replace the weakest retained score. Sorting all n scores is simpler for a small batch, but stores the batch and takes O(n log n) time.

Lesson 11 / Medium

Prefix sums & counting

Subarray Sum Equals K ↗ LC 560

Know first Lesson 1’s complement lookup. A prefix sum is the sum of everything before a boundary.

Count contiguous, nonempty slices summing to k. Values can be negative or zero.

Reason it out

If the running total is s, any earlier boundary with total s − k starts a slice ending here with sum k. Count how often each earlier total occurred. Seed the empty prefix so slices starting at index 0 count.

Python solution & edge cases 
def count_subarrays(nums, k):
    frequency = {0: 1}
    total = count = 0
    for value in nums:
        total += value
        count += frequency.get(total - k, 0)
        frequency[total] = frequency.get(total, 0) + 1
    return count

Run these checks

assert count_subarrays([1, -1, 1], 1) == 3
assert count_subarrays([0, 0], 0) == 3
assert count_subarrays([4, -1], 3) == 1

Cost O(n) expected time · O(n) extra space for distinct prefix totals.

Pitfall Look up the frequency before incrementing it. When k = 0 the opposite order counts an empty slice. A set loses multiple boundaries with the same total.

Why can’t we shrink a window whenever the sum exceeds k?

Negative numbers can bring the sum down later. For [4, −1] and k = 3, dropping the 4 early throws away the only answer.

Lesson 12 / Medium

Directed graphs & topological sort

Course Schedule ↗ LC 207

Know first Lesson 8’s queue. An adjacency list stores outgoing neighbors. Indegree counts incoming edges.

Can you complete every course? Each pair [course, prerequisite] requires the prerequisite to finish first.

Reason it out

Draw edges from prerequisite to course. Queue all courses with zero remaining prerequisites. Finishing one removes one dependency from each outgoing neighbor. If some courses remain but none is ready, a dependency cycle blocks completion.

Python solution & edge cases 
from collections import deque

def can_finish(n, prerequisites):
    outgoing = [[] for _ in range(n)]
    degree = [0] * n
    for course, pre in prerequisites:
        outgoing[pre].append(course)
        degree[course] += 1
    ready = deque(i for i in range(n) if degree[i] == 0)
    finished = 0
    while ready:
        course = ready.popleft()
        finished += 1
        for neighbor in outgoing[course]:
            degree[neighbor] -= 1
            if degree[neighbor] == 0:
                ready.append(neighbor)
    return finished == n

Run these checks

assert can_finish(4, [[2,0], [2,1], [3,2]])
assert not can_finish(3, [[0,1], [1,0]])
assert can_finish(2, [])

Cost O(V + E) time · O(V + E) extra space for V courses and E prerequisite pairs.

Pitfall Start from all zero-indegree courses, including isolated vertices. A directed cycle in one component blocks a full schedule even when another component finishes.

How would you return one valid order?

Append each course to a list as it leaves the queue. Return that list only if it contains all courses. Several orders can be correct when multiple courses are ready.

Lesson 13 / Medium

Weighted graphs & Dijkstra

Network Delay Time ↗ LC 743

Know first Lesson 10’s heap and lesson 12’s outgoing edges. Edge weights are nonnegative travel times.

A signal starts at k. Find the earliest time by which every node has received it, or −1 if any node is unreachable.

Reason it out

Keep the fastest known arrival for each node. A min-heap gives the next earliest arrival. When the cheapest live entry is popped, no unfinished route can improve it because every additional edge costs at least zero. The last recipient determines the answer.

Python solution & edge cases 
from heapq import heappop, heappush

def network_delay(times, n, k):
    outgoing = [[] for _ in range(n + 1)]
    for start, end, weight in times:
        outgoing[start].append((end, weight))
    dist = [float("inf")] * (n + 1)
    dist[k] = 0
    heap = [(0, k)]
    while heap:
        time, node = heappop(heap)
        if time != dist[node]:
            continue
        for neighbor, weight in outgoing[node]:
            arrival = time + weight
            if arrival < dist[neighbor]:
                dist[neighbor] = arrival
                heappush(heap, (arrival, neighbor))
    last = max(dist[1:])
    return -1 if last == float("inf") else last

Run these checks

assert network_delay([[1,2,8], [1,3,1], [3,2,2]], 3, 1) == 3
assert network_delay([[1,2,2]], 3, 1) == -1
assert network_delay([[2,1,0]], 2, 2) == 0

Cost O((V + E) log(V + E + 1)) time · O(V + E) extra space, including queued offers and the adjacency list.

Pitfall A vertex can enter the heap more than once. Skip an offer if its time is stale. Marking it finished at first discovery would lock in the direct time 8.

When is ordinary BFS enough?

When each edge costs the same, fewer edges gives a cheapest path. With differing costs a longer route can arrive first. Negative weights require a different method such as Bellman–Ford.

Lesson 14 / Medium

Recursion & backtracking

Subsets ↗ LC 78

Know first A function call remembers its own index. A list passed through nested calls remains the same mutable object.

Generate every subset of a list of distinct values, including the empty subset. Any order is valid.

Reason it out

For each value make two choices, skip it or take it. At the end of a path save a copy. Undo a take when returning so the caller sees exactly the choices it had before.

Python solution & edge cases 
def subsets(nums):
    result = []
    path = []

    def visit(i):
        if i == len(nums):
            result.append(path.copy())
            return
        visit(i + 1)
        path.append(nums[i])
        visit(i + 1)
        path.pop()

    visit(0)
    return result

Run these checks

assert sorted(subsets([2, 5])) == [[], [2], [2, 5], [5]]
assert subsets([]) == [[]]

Cost O(n × 2ⁿ) time including copying · O(n) working space plus O(n × 2ⁿ) output for n ≥ 1.

Pitfall Appending path itself stores the same list repeatedly. Forgetting pop also leaks choices into sibling branches.

Why can’t a much faster algorithm return all the same lists?

There are 2ⁿ subsets and each of the n items appears in half of them. Returning explicit lists requires writing n × 2ⁿ⁻¹ item references for n ≥ 1.

Lesson 15 / Medium

Prefix trees (tries)

Implement Trie (Prefix Tree) ↗ LC 208

Know first Dictionary lookup from lesson 1. Each edge in this tree represents one character.

Support inserting lowercase words, looking up whole words and testing whether any stored word begins with a prefix.

Reason it out

Share the work for common prefixes. Each node owns a dictionary of children and one flag saying a whole word ends here. A walk that reaches a node proves the prefix exists. Read the flag for a full-word query.

Python solution & edge cases 
class Trie:
    def __init__(self):
        self.children = {}
        self.word_end = False

    def insert(self, word):
        node = self
        for char in word:
            if char not in node.children:
                node.children[char] = Trie()
            node = node.children[char]
        node.word_end = True

    def _walk(self, text):
        node = self
        for char in text:
            if char not in node.children:
                return None
            node = node.children[char]
        return node

    def search(self, word):
        node = self._walk(word)
        return node is not None and node.word_end

    def startsWith(self, prefix):
        return self._walk(prefix) is not None

Run these checks

trie = Trie()
trie.insert("cart")
assert trie.startsWith("ca") and not trie.search("ca")
assert not trie.search("car")
trie.insert("car")
assert trie.search("car") and trie.search("cart")
assert not trie.startsWith("cat")

Cost O(L) expected time per operation for L characters · up to O(L) new nodes per insertion. Storage is proportional to the number of distinct prefixes.

Pitfall A leaf-only word test loses 'car' after inserting 'cart'. Searching for a missing edge should leave the trie unchanged.

Would a set of full words work?

Yes for exact membership. Prefix lookup would require scanning words or maintaining a second index. A trie also lets autocomplete descend from the final prefix node.

Lesson 16 / Medium

One-dimensional dynamic programming

House Robber ↗ LC 198

Know first Lesson 14’s take/skip choices. A DP state is an answer to a smaller version of the same question.

Choose nonadjacent houses from a line of nonnegative amounts. Maximize the total.

Reason it out

Let best(i) mean the most money from the first i houses. Skip the last house and keep best(i−1), or take it and add its money to best(i−2). These exhaust the possibilities. Start both saved totals at zero for the empty prefix.

Python solution & edge cases 
def rob(nums):
    two_back = one_back = 0
    for money in nums:
        current = max(one_back, two_back + money)
        two_back, one_back = one_back, current
    return one_back

Run these checks

assert rob([4, 5, 4]) == 8
assert rob([6]) == 6
assert rob([0, 0]) == 0

Cost O(n) time · O(1) extra space. The recurrence reads only the previous two totals.

Pitfall Both updates need the old values. Assigning prev first and then using its new value in the sum can allow adjacent houses.

How could you return the chosen houses as well?

Keep a table of prefix answers. Walk backward. If a skip preserves the optimum, skip that house. Otherwise record it and move back two positions.

Lesson 17 / Medium

Two-dimensional dynamic programming

Unique Paths ↗ LC 62

Know first Grid coordinates from lesson 8 and the state/recurrence idea from lesson 16. Rows and columns both have positive size.

Count routes from the upper left to lower right of a grid. Each move goes either one cell down or one cell right.

Reason it out

Let ways[r,c] count routes ending at a cell. Its last move came from above or from the left. Those two groups cannot overlap, so add their counts. The first row and column each have one route. Reuse one row since later cells need only their upper and left neighbors.

Python solution & edge cases 
def unique_paths(rows, cols):
    ways = [1] * cols
    for r in range(1, rows):
        for c in range(1, cols):
            ways[c] += ways[c - 1]
    return ways[-1]

Run these checks

assert unique_paths(3, 4) == 10
assert unique_paths(1, 5) == 1
assert unique_paths(5, 1) == 1

Cost O(rows × cols) time · O(cols) extra space. A full table is easier to draw and gives the same answer.

Pitfall Iterate columns from left to right. ways[c−1] must already belong to the current row, while ways[c] still belongs to the previous row.

What changes if there are blocked cells?

Use a zero-filled row and seed the starting column with one. Scan the whole grid. Set a blocked cell to zero. For other cells with c > 0 add ways[c−1]. This also handles a blocked start.

Lesson 18 / Medium

Greedy reachability

Jump Game ↗ LC 55

Know first Index arithmetic and a running maximum. Each value gives a maximum forward jump, so all shorter jumps are legal.

Starting at index 0 of a nonempty list, can you reach the last index?

Reason it out

All reachable indices form a continuous prefix starting at zero. From any reachable i, jumps extend that prefix up to i + nums[i]. Keep the largest such endpoint. A gap beyond it can never be crossed by an earlier position.

Python solution & edge cases 
def can_jump(nums):
    farthest = 0
    for i, jump in enumerate(nums):
        if i > farthest:
            return False
        farthest = max(farthest, i + jump)
    return True

Run these checks

assert can_jump([2, 2, 0, 1, 0])
assert not can_jump([1, 0, 2])
assert can_jump([0])

Cost O(n) time · O(1) extra space. One boundary replaces a table of reachable positions.

Pitfall A zero can be jumped over. Always check that i is reachable before using its jump length.

Does success also tell you the fewest jumps?

It only proves reachability. For minimum jumps, track the end of the current jump range and the farthest end seen inside it. Crossing a range boundary consumes one more jump.

Lesson 19 / Easy

Bit manipulation

Single Number ↗ LC 136

Know first An integer is a sequence of bits. XOR (^) sets a bit to 1 exactly when its two input bits differ.

Exactly one integer appears once. Every other integer appears twice. Recover the single value using constant extra space.

Reason it out

XOR with zero preserves a number. XOR with itself gives zero. Since order and grouping do not affect XOR, all complete pairs cancel even when separated.

Python solution & edge cases 
def single_number(nums):
    result = 0
    for value in nums:
        result ^= value
    return result

Run these checks

assert single_number([6, 3, 6]) == 3
assert single_number([-2, 0, 0]) == -2
assert single_number([0]) == 0

Cost O(n) time · O(1) extra space for fixed-width input integers. Python’s cost per XOR grows with integer bit length.

Pitfall ^ is XOR in Python. ** raises to a power. Pair cancellation relies on the promised occurrence counts.

What if two different numbers each occur once?

The XOR of all values becomes a ^ b. Pick a set bit in that result. Split values by that bit and XOR within each group. The two unique values land in different groups and the pairs still cancel.

Lesson 20 / Medium

Matrix geometry

Rotate Image ↗ LC 48

Know first Square n × n grid, row and column indices, swapping two values in Python.

Rotate an n × n image clockwise by 90° in place. The caller should see the change in the same matrix.

Reason it out

Follow one cell at (r,c). A transpose sends it to (c,r). Reversing each row then sends it to (c,n−1−r), exactly the clockwise destination. Transpose only across one triangle so each pair swaps once.

Python solution & edge cases 
def rotate(matrix):
    n = len(matrix)
    for r in range(n):
        for c in range(r + 1, n):
            matrix[r][c], matrix[c][r] = matrix[c][r], matrix[r][c]
    for row in matrix:
        row.reverse()

Run these checks

matrix = [[1,2,3], [4,5,6], [7,8,9]]
rotate(matrix)
assert matrix == [[7,4,1], [8,5,2], [9,6,3]]
matrix = [[1]]
rotate(matrix)
assert matrix == [[1]]

Cost O(n²) time · O(1) extra space. The swaps and row reversals operate on the input.

Pitfall Swapping the full square undoes every exchange. matrix = rotated only rebinds a local name. Verify the direction with a corner cell.

How would you rotate counterclockwise?

After transposing, reverse the order of the rows. The destination becomes (n−1−c,r). A fresh output grid also makes either coordinate mapping easy when extra space is allowed.

Final interview rehearsal

Close the solutions. For each prompt, name the state you would keep, give its cost, and trace one input that breaks a tempting shortcut.

Scores arrive continuously. How do you keep the best five?

A size-five min-heap keeps the weakest retained score at its root. On a larger arrival, replace the root. Ask how ties should be handled and whether the five must be displayed in order. Lesson 10 covers the cutoff.

A job waits on two other jobs. Can all jobs run?

Use a directed graph and count unfinished prerequisites. Start each job when that count becomes zero. If the queue drains before all jobs finish, look for a cycle. Try a two-job cycle plus one independent job. See lesson 12.

A range of daily changes must total three. Is a moving window safe?

Clarify whether changes can be negative. The range [4, −1] totals three even though the first value exceeds three. Count earlier prefix totals equal to current total minus three. See lesson 11.

When you get stuck, give a correct brute-force solution and name its repeated operation. Ask what would let you avoid doing that operation twice. Before finishing, test the smallest allowed input and a case with duplicates, a boundary, or a disconnected component.
